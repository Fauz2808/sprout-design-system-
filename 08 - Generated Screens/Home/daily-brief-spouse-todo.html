Tony, 17 Sep: “From parent to parent, like me to my wife. And if we can get the spouses using it with the reminders, then… that’s half the battle.”

Two lists, one scroll

Yours never moves. Theirs sits directly under it, above Carpool, because it answers the same question: what is still left today.

Tony’s phoneYours folded, hers open. Your list, then theirs, in one scroll. Yours is done so it has collapsed; hers has one item left so it stays open. That is the rule: a finished list folds, an unfinished one does not — so the screen always opens on whatever is actually left, whoever it belongs to. The ring on her card reads 1/3 at a glance, which is the whole point of the section.
The one hard rule here: her rows carry a status dot, not a checkbox. The shape carries it without a word of copy — square boxes are yours and tappable, round dots are theirs and are not. You cannot tick her items. Ticking work you did not do makes the list lie, and a list that lies is worse than no list — it is exactly the thing that would make Tony stop trusting the 1/3.
