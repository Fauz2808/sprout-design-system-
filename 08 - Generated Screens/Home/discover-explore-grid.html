Same component, 5 / 6 / 7 categories

Replaces the stacked "Parks and Playgrounds / Beer Gardens / Indoor Play / Restaurants / Birthday Venues" list with one 2-column tile grid — same pattern Uber uses for Rides/Reserve/Rental/Send/Food/Grocery, in Sprout's own colors (the green badge is already Sprout's brand green). Add or remove a tile and the grid reflows — that's the "regional" part: a smaller market ships 5 tiles, a bigger one ships 7, same code. When the count is odd the last tile auto-spans full width so it never looks unbalanced.
