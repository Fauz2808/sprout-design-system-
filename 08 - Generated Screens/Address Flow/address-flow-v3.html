Tony's feedback → what changed
Search hides action rows when typing
"As soon as I engage with the search, it should populate only the search stuff." — action rows slide away, only results show. Two states: idle and typing.
Label chips replace free-text input
"I shouldn't have to type it out. Home, school, work — just select it." Home / School / Work / Other. Tapping Other reveals a custom text field.
Current location resolves to real address
"What does it show when I hit current location?" — resolves to street + city format (e.g. 10212 Banks Ct, Austin TX). Same confirm flow as manual search.
