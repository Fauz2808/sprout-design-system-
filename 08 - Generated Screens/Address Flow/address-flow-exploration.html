What changed

Map removed. Flow simplified. Every screen now follows the DoorDash sheet template.

Before — single screen with map

  • One screen does everything: map, name, address, tag.
  • Map takes ~25% of screen on every step — even when irrelevant.
  • Two competing CTAs split user attention (Set as Default + Save Address).
  • "Tag" is unlabeled in purpose — users don't know what it does.
  • No place for delivery details (apt, drop-off instructions).

After — DoorDash structure, our brand

  • No map. Removed entirely — autocomplete is enough to identify the address.
  • Four atomic steps, each a full-cover sheet with ONE primary action.
  • Same template every screen: drag handle → back + title → bold body heading → focused input → warm callout → single sage CTA.
  • Step 3 mirrors DoorDash's Set Label one-to-one: free-text input, "Address Label" heading, warm callout, Continue button.
  • Cream surface + sage primary preserved — only the architecture changed.
