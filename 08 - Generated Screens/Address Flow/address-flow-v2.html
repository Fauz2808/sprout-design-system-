Address flow · v2 — fixes applied
  • 1
    Set Address — Empty
    No saved addresses. Tap "Add new address" or the search bar.
  • 2
    Set Address — Saved
    Two standardized cards. Star always visible. Tap star to set default. Tap edit → screen 5.
  • 3
    Find Address
    Keyboard up, results visible. Tap any result → Confirm Address (step 4).
  • 4
    Select Address (new)
    Confirms the picked address with a map view. "Add this address" pre-fills and advances to Set Address.
  • 5
    Set Address
    Street + full address auto-filled from selection. User only adds a label.
  • 6
    Edit Address
    Asterisk consistent with Set form. Delete is outline-style, triggers confirmation sheet.
