Print production notes

Both sides as "front": Each face is a complete standalone hook — same visual system, parallel social-proof message. A passerby seeing only one side still gets the full pitch.

Use different UTM per side: Same landing page, but tag fronts as utm_content=front and backs as utm_content=back so you can measure which message converts better.

Sign orientation in the field: Place landscape signs perpendicular to traffic flow (one face toward each direction). Portrait signs work best at angles where they're visible to both foot and car traffic.

School-specific batch printing: For Concept 2, keep the base file identical and only swap the yellow tag text. Most printers will treat this as a single SKU with text variants — minimal cost difference vs a single design.
