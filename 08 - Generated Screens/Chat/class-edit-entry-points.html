Renaming a class — the way in that was missing

Tony could not rename Miss Taylor's Class from the class itself. The editor exists and always has. What is missing is a door on the screen he actually lands on.

Tony, 15 Sep: “I have Miss Taylor's class. If I click Miss Taylor's class and I go into here, I can't actually edit anything here. The way I actually can edit, and it's kinda like, I had to figure it out, you have to go into Add, and then you go to, and then I have to click Edit and get to here. But this edit also needs to live behind here too. So if I click here, there should just be an edit thing there as well.”

What he had to do

  1. Open the Chat tab
  2. Tap +, the add button
  3. Land on Manage Subgroups
  4. Find the class in that list
  5. Tap Edit
Five taps, and the third one is a screen called Add, which is not where anyone looks to change something that already exists.

What he tried, and what it will now do

  1. Open the class
  2. Tap its name in the header
  3. Tap Edit name & icon
No new editor is built. This is routing: two controls that already sit in the header get a destination.

What was actually wrong

Two things, and neither is the editor. The class header already draws a three-dot button that opens nothing, and the name beside it is not tappable. Meanwhile a club has Manage on its own detail screen, which is why Tony found that one in seconds and said never mind.
