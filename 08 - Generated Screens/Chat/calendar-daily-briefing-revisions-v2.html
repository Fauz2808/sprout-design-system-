Reminders section removed: per the 2026-09-09 call, No School and Pizza Day now live in Happening today as full-day cards, and the Little Shots soccer note was already the same event as the 3:30 pm entry above it — so all three lines that used to sit under Reminders are now accounted for elsewhere. Yearbook line removed from Upcoming events: per the same review — "we don't need the to do because that's gonna live in the reminders and to do thing" — a to-do-flavored item doesn't belong mixed into Upcoming events, so "Last day to order yearbooks" is cut from this section (it can live in To do instead if it still needs surfacing).
