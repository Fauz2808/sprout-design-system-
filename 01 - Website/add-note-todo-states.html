Build notes for Syed

  • To-Do is the 4th note type. Selecting it swaps the form to: one-line describe + optional deadline + optional link + Assign-to. Event / No School / Special keep their Title + Details form (no assign-to).
  • "Describe to-do" is the field label (not "Title"). One line, no details field.
  • Empty state (1): field is blank + auto-focused (keyboard opens). Placeholder only — never pre-fill text.
  • Deadline + link are optional — both can be left unset. Deadline uses the platform native date picker; link is a plain URL field.
  • Assign-to: Everyone (default) · Specific · Just me. The hint line under the segment changes per mode (states 2/4/6).
  • Specific (4 & 5): opens the people sheet — full group, searchable, with Select all / Clear and a "Done · N selected" button. Selecting writes back to the "Choose people" summary row. This replaces the old cramped 2-name list.
  • Use the live prototype add-note-todo-single.html as the source of truth for spacing, colors, and interactions.
