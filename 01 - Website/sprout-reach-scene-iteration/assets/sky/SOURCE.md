# Hero sky loop

From Ahmad's own Recreate Library, `recreations/mercury` (the fictional "Cove · Open Sky" concept),
`public/brand-guide/assets/motion/`. Original generated footage (see that package's ASSETS.md and
motion-kit/); its license allows use in personal and commercial projects. Copied 6 Oct 2026.

- hero-loop-desktop.{av1,h264}.mp4: 1920 x 1080, 6.4 s loop.
- hero-loop-mobile.{av1,h264}.mp4: a centred 608 x 1080 crop of the same loop.
- sky-desktop.webp / sky-mobile.webp: frame 0 of each loop, the poster, so still and video line up.

The laptop never moves (the loop is locked to the still), so its screen can carry live HTML.
Screen in desktop-loop pixels: left 778, top 527, right 1133, bottom 746 (from Cove's documented
1672 x 941 corners x 1920/1672). The mobile loop is the same frame cropped 656 px from the left.
