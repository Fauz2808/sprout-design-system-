# Sprout — Parenting on Easy Mode

A standalone landing-page variation based on the leadership brief. It reframes Sprout around one continuous flow: Daily Brief, class resources, Voice AI, parent directory, weekend planning, and the community problems Sprout resolves.

## Preview

Serve this directory with any static server. This variation intentionally stays separate from `sprout-reach-scene`.
