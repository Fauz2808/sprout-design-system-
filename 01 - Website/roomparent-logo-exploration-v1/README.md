# Room Parent logo v1

## Concept

The mark is a custom capital `R` with an open doorway built into its negative space. The `R` makes the small mark identifiable without repeating a generic school symbol. The doorway represents one calm, shared place where room parents coordinate a classroom.

This direction intentionally avoids every Sprout cue: no leaf, sprout, clover, four-lobed shape, or parent-app reference.

## Color

- Primary forest: `#183E2A`
- Warm cream: `#F4F1EA`
- Dark supporting ink: `#1E2A22`

## Usage

- Use the horizontal lockup in the public landing page header and footer when space allows.
- Use the standalone mark in the portal sidebar, auth screens, favicon, and social avatar.
- Minimum standalone mark size: 24 px in product UI. The 16 px file is reserved for browser favicon use.
- Keep clear space around the mark equal to the width of its doorway.
- Do not add a Sprout byline or app-related endorsement.
- Do not place the mark inside a clover, leaf, badge, or school seal.
